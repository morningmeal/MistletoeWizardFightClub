# MistletoeWizardFightClub
# ⚡ 미슬토 위저드 결투 클럽
해리 포터 세계관을 모티브로 한 1:1 마법 대결 시뮬레이터입니다.  

---

## 🪄 주요 기능

- **캐릭터 커스텀 생성 & 프리셋 저장**
  - 캐릭터 사진(Base64 이미지 업로드 지원), 이름, 학년(1~7학년), 기숙사, 지팡이 설정 가능
  - 브라우저 로컬 저장소(localStorage)를 통한 슬롯별 캐릭터 저장 및 불러오기
- **스탯 배분 & 보정치 시스템**
  - 기숙사, 지팡이 목재, 지팡이 심에 따른 고유 스탯 가점 부여
  - 캐릭터 생성 완료 시 '운(행운)' 스탯 1~3 무작위 부여
- **7턴 턴제 전투 시뮬레이션**
  - 자동 선공 결정
  - 열정 vs 신중 스탯 비율에 따른 실시간 대응(방어/반격) 자동 선택
  - 공격, 방어 경감, 반격, 크리티컬 판정 및 턴별 상세 전투 로그 제공
- **결과 이미지 저장**
  - 결투 종료 후 결투 결과 요약 카드를 고해상도 PNG 이미지 파일로 즉시 다운로드

## 📊 규칙 및 공식 가이드

### 1. 학년별 포인트 투자량
| 학년 | 투자 가능 포인트 |
|---|---|
| **1~2학년** | 9 P |
| **3~5학년** | 11 P |
| **6~7학년** | 13 P |

*투자 가능 스탯: 의지, 열정, 신중, 속도 (운은 생성 완료 시 1~3 중 무작위 부여)*

### 2. 가점 및 보정치
- **기숙사**:
  - 그리핀도르: 의지 +1
  - 후플푸프: 열정 +1
  - 슬리데린: 신중 +1
  - 래번클로: 속도 +1
- **지팡이 목재**:
  - 편백나무: 의지 +1
  - 사시나무: 열정 +1
  - 주목: 신중 +1
  - 적참나무: 속도 +1
- **지팡이 심**:
  - 용의 심근: 열정 +1
  - 유니콘의 털: 신중 +1

### 3. 전투 환산 공식
- **초기 체력**: `100 + (의지 × 10)`
- **기본 공격력**: `10 + (열정 × 2)`
- **기본 방어력**: `10 + (신중 × 2)`
- **기본 민첩성**: `1 + (속도 × 1)`
- **크리티컬 확률**: `10% + (운 × 2)%` (치명타 발동 시 피해량/방어량에 +5 추가)

### 4. 대결 수치 산출 공식
- **공격 데미지**: `[1 ~ 공격력] 랜덤 정수 + ⌊공격력 / 3⌋`
- **방어량**: `[1 ~ 방어력] 랜덤 정수 + ⌊방어력 / 2⌋`
- **반격 데미지**: `[1 ~ (공격력 - 4)] 랜덤 정수 + ⌊공격력 / 4⌋`

### 5. 전투 흐름 및 승패 판정
1. **선공 판정**: 각 턴 시작 시 `1 ~ 민첩성` 주사위를 굴려 높은 쪽이 선공
   - 동점일 경우 기본 민첩성이 높은 쪽 선공, 스탯도 같다면 50% 확률로 무작위 결정
2. **대응 선택**: 수비자는 자신의 `열정 : 신중` 스탯 비율에 따라 방어 또는 반격을 선택
   - **방어**: 공격자의 피해량을 자신의 방어량만큼 차감
   - **반격**: 공격자의 피해를 그대로 입는 대신, 자신도 반격 피해를 공격자에게 입힘
3. **진행 순서**: 선공 공격 ➔ 후공 대응 ➔ 중간 정산 ➔ 후공 공격 ➔ 선공 대응 ➔ 최종 정산
4. **승리 판정**:
   - 7턴 진행 중 어느 한쪽의 체력이 0 이하가 되면 즉시 결투 종료
   - 7턴 종료 시: 잔여 체력이 높은 쪽 ➔ 누적 피해를 더 많이 준 쪽 ➔ 무승부
